# ADR 0001: SoftPreferences живёт в contracts

- Статус: принят
- Дата: 2026-08-19

## Контекст

`SoftPreferences` вводится пользователем во frontend, валидируется API и влияет
на domain/solver. Локальные копии типа быстро расходятся: UI может отправить
поле, которое API отбросит, или solver не сможет интерпретировать.

## Решение

Zod-схема и TypeScript-тип `SoftPreferences` находятся в
`@rendezvous/contracts`. Frontend, API, domain и solver импортируют одну схему;
на границах ввода выполняется её runtime-валидация. Бизнес-правила и расчёт
штрафов остаются в domain/solver и не переносятся в contracts.

## Последствия

Изменение предпочтений требует обратимо-совместимого изменения контракта и
контрактных тестов. UI не создаёт отдельный transport-тип. Текстовое пожелание
сначала преобразуется в известные поля, затем проходит ту же Zod-схему.
