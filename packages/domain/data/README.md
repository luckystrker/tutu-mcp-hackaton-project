# City catalog v1

`cities.v1.json` — curated MVP-каталог из 110 городов России и ближнего зарубежья.

- Координаты центров округлены до 4 знаков после запятой по общедоступным географическим справочникам (GeoNames/OpenStreetMap).
- `tz` использует идентификаторы IANA из системной timezone database.
- `hubScore` — ручная шкала MVP, а не travel fact: 90–100 — национальные и крупнейшие multimodal hubs; 75–89 — крупные региональные hubs; 60–74 — устойчивые региональные связи; ниже 60 — малые туристические города с ограниченной связностью.
- Tags — курируемые product labels и используются только как soft boost.

Версия каталога: `cities-v1.0.0`. Изменение состава, координат или методики `hubScore` требует новой версии каталога и `candidateAlgorithmVersion`.
